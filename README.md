# IPO Radar Global v3 📡 — رادار اكتتابات مع إشعارات الهاتف

نسخة PWA عربية قابلة للتثبيت على Android (Samsung/Chrome) بعد نشرها مجاناً على HTTPS. تبحث يومياً عن **إشارات تستحق البحث**، ولا تتداول آلياً.

**حالة التشغيل (26 أكتوبر 2026):** التطبيق منشور على https://emadtafas-prog.github.io/ipo-radar-global/ وقد نجح أول فحص عبر GitHub Actions. اشتراك Web Push وإرسال التنبيهات ما زالا بحاجة لاختبار الجهاز وإضافة OneSignal API Key السري في GitHub Secrets. التحليل الذكي غير مفعل دون مفتاح OpenAI API. لا يوجد APK ضمن هذه الحزمة؛ عند تثبيت PWA من Chrome/Samsung Internet يصبح التطبيق في الشاشة الرئيسية ويعمل كواجهة مستقلة. ملف ZIP نفسه ليس تطبيق Android قابلًا للتثبيت بضغطة واحدة.

## الأسواق والمصادر في هذه النسخة

| السوق | ماذا يجري فحصه؟ | درجة التحقق | إعداد مطلوب |
|---|---|---|---|
| أوروبا (Paris, Amsterdam, Brussels, Oslo, Milan وغيرها) | صفحة Coming/Recent IPOs في Euronext | رسمي؛ لكن صفحة قد تتغير | لا |
| بريطانيا (LSE / AIM) | قسم Upcoming new equity issues | رسمي؛ ليس كل إصدار IPO | لا |
| الولايات المتحدة | تسجيلات S-1 وF-1 من SEC | تسجيل رسمي **غير معادل للاكتتاب** | `SEC_CONTACT` |
| أمريكا وأسواق أخرى يذكرها المزود | Finnhub IPO Calendar | تقويم تقديري غير رسمي | `FINNHUB_TOKEN`، وفّر صلاحية واجهة التقويم |
| ألمانيا، الهند، هونغ كونغ، السعودية، الإمارات، اليابان، كوريا الجنوبية، كندا، أستراليا، سنغافورة، البرازيل | عناوين بحث إخبارية حديثة عبر Google News RSS | **خبر غير مؤكد** وليس إدراجاً معتمداً | لا |

**مهم:** «تغطية أسواق عالمية» تعني تغطية متعددة المستويات، ولا تعني وجود خدمة بيانات إدراج رسمية لكل بورصة. عند تعذّر المصدر سيظهر في قسم حالة المصادر داخل التطبيق. RSS غير مضمون وقد تتغير بنيته أو شروط وصوله.

## تشغيل حقيقي في أقل عدد من الخطوات (مرة واحدة)

1. امتلك حساباً في [GitHub](https://github.com/). أنشئ مستودع **Public** باسم `ipo-radar-global`، وارفع **محتويات هذا المجلد** إلى جذر المستودع، مع `.github/workflows/daily.yml` (تأكد من إظهار الملفات المخفية). الكود معروض للعموم في مستودع Public، لذلك لا تضع مفاتيح أو معلومات شخصية فيه. يمكن توصيل تطبيق GitHub إلى ChatGPT للمساعدة في النشر بشرط موافقة صاحب الحساب.
2. في **Settings → Pages → Build and deployment** اختر **Source = GitHub Actions**.
3. افتح **Actions → IPO Radar Global daily scan and publish → Run workflow**، ثم انتظر ظهور علامة النجاح. تبدأ الأسواق الأوروبية والبريطانية والمراقبة الإخبارية من دون أي مفاتيح. قد تفشل بعض المصادر أو تمنع الاستعلام الآلي؛ تحقق من **قسم حالة المصادر** في الواجهة قبل الاعتماد عليها.
4. افتح **Settings → Pages** لتحصل على الرابط العام، وعادةً شكله `https://YOUR_USERNAME.github.io/ipo-radar-global/` إذا استُخدم اسم المستودع المقترح. هذا مجرد **نمط لرابط** وليس رابطاً أنشأناه بالفعل.
5. على Samsung S24: افتح الرابط في **Chrome** أو **Samsung Internet** ثم القائمة **⋮ → تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**. ستجد أيقونة IPO Radar على شاشة الهاتف. تتطلب عملية التثبيت رابط HTTPS منشوراً؛ فتح `index.html` كملف محلي لا يكفي لتثبيت PWA حقيقية.

### تشغيل المصادر الأمريكية (اختياري لكنه مفيد)

في **Settings → Secrets and variables → Actions → New repository secret** أضف:

- `SEC_CONTACT`: بريد إلكتروني صحيح لتحديد هوية طلبات SEC وفق قواعد الاستخدام. لا تضع البريد في ملفات المصدر العامة.
- `FINNHUB_TOKEN`: مفتاح [Finnhub](https://finnhub.io/) إذا كانت واجهة IPO Calendar متاحة ضمن خطتك. بعض البيانات قد تتطلب اشتراكاً مدفوعاً.

### 🔔 إشعارات الهاتف عبر التطبيق — بلا Telegram

الإشعارات نوعان، والفرق مهم:

- **مركز الإشعارات داخل IPO Radar:** مدمج ومتاح بعد تشغيل الماسح؛ يسجل الإشارات الرسمية الجديدة من نوع أوراق تسجيل IPO أو الطروحات/الإدراجات الجديدة. يتيح مشاهدة المصدر وتحديد الرسائل كمقروءة. لا يظهر سجل تنبيهات تاريخية وهمية في أول فحص.
- **Push Notifications على شاشة Samsung حتى لو التطبيق مغلق:** تحتاج رابط HTTPS منشوراً + تسجيل تطبيق **Web Push** في [OneSignal](https://onesignal.com/) + موافقة إشعارات الموقع داخل Chrome. هذه خدمة توصيل الإشعارات داخل IPO Radar، وليست تطبيق محادثة منفصلاً مثل Telegram.

خطوات التفعيل (مرة واحدة بعد نشر GitHub Pages):

1. أنشئ مشروع OneSignal من نوع **Web Push** واضبط Site URL بحسب متطلبات OneSignal الخاصة بعنوان الموقع، مع مراجعة النطاق `https://emadtafas-prog.github.io` ومسار التطبيق الفرعي. تأكد أن الإعدادات تدعم صفحة الموقع بمسار فرعي وأن ملف عامل الإشعارات المنشور موجود في `/ipo-radar-global/onesignal/OneSignalSDKWorker.js`، لا جذر النطاق. هذا الملف يستخدم نطاق Service Worker منفصلاً حتى لا يتعارض مع عمل PWA بدون إنترنت. إذا كانت واجهة OneSignal أو متطلبات النطاق لا تسمح بهذا النشر، استخدم نطاقاً مخصصاً HTTPS ثم أعد ضبط URL والإعدادات.
2. تم بالفعل ربط **App ID** العام في إعدادات workflow وإعدادات واجهة المشروع. لا داعي لإضافة `ONESIGNAL_APP_ID` يدوياً.
3. خذ **REST API Key** (قد يُسمى App API Key) وضعه في **Secrets** باسم `ONESIGNAL_REST_API_KEY`، ولا تضعه داخل `index.html` أو `push-config.json` أو أي ملف عام.
4. تم بالفعل ضبط `APP_URL` على رابط المشروع المنشور. شغّل Workflow يدوياً بعد إعداد المفتاح السري وأعد فتح التطبيق.
5. من Chrome على Samsung اضغط زر **تفعيل إشعارات الهاتف** واسمح بالإشعارات. جرّب إرسال اختبار عبر OneSignal Dashboard ثم راقب حالة الاشتراك.

**تنبيه:** هذا إعداد مدمج بالكود ولكنه **غير مفعل** حتى تُنشئ حساب OneSignal وتربطه بنطاق التطبيق. لا يمكن التحقق من استلام الإشعارات الحقيقية على الهاتف من بيئة التطوير. OneSignal خدمة خارجية، ويعتمد السعر على خطتك وعدد المتلقين وشروط الخدمة. راجع سياسة خصوصيتها قبل الاشتراك.

**توقيت الإرسال:** GitHub Actions يكتشف إشارات جديدة في وقت الفحص اليومي وليس لحظياً. ترسل رسالة Push موجزة للإشارات الرسمية التي اكتُشفت بعد الفحص الأول فقط، بحد أقصى عملي مقدمة تتضمن أهم 3 أسماء وإجمالي العدد. الإشارات الأقدم من 48 ساعة لا تُرسل عند تفعيل الخدمة لاحقاً. تتم محاولة منع التكرار، لكن فشل حفظ حالة GitHub أو إعادة المحاولة قد يؤدي أحياناً إلى تكرار الإرسال. موقع التطبيق عام، لذلك يمكن لمستخدمين آخرين الاشتراك ما لم تضف مصادقة لاحقاً.


### تحليل AI (اختياري ومدفوع منفصلاً)

أضف `OPENAI_API_KEY` كـ GitHub Secret إذا أردت ملخصات AI مدعومة بمصادر. الخطة تسمح بحد أقصى تحليل عنصرين في التشغيل اليومي؛ يتطلب رصيد OpenAI API منفصلاً عن اشتراك ChatGPT. **الذكاء الاصطناعي لا يتنبأ بأسعار مؤكدة ولا يعطي أوامر تداول.** يعمل الرادار بدونه.

## آلية العمل

- يعمل مسح GitHub Actions يومياً الساعة **14:12 بتوقيت Europe/Berlin**، مع التوقيت الصيفي/الشتوي. قد تتأخر المجدولات وليست آلية لحظية.
- تُحفظ النتائج والتنبيهات (`alerts`) في `data/signals.json` وتُعرض عبر GitHub Pages؛ هذه البيانات **عامة**، والمفضلة وحالة قراءة الإشعارات **محلية** في المتصفح الخاص بك.
- حالة كل مصدر: ناجح / تعذّر الاتصال / يحتاج مفتاح. يتم تسجيل آخر وقت رُصدت فيه كل إشارة، وتظل الإشارات السابقة ظاهرة لفترة لا تزيد عن 120 يوماً إذا غاب المصدر، مع بيان آخر رصد.
- تصفية حسب البلد والنوع، مفضلة محلية، تنزيل CSV، مركز إشعارات مدمج وإذن Push اختياري، تجربة ببيانات **خيالية صريحة**.
- المصادر المتغيرة قد توقف عمل جامع البيانات، وتتطلب صيانة دورية. راجع صفحة Actions وحالة المصادر على الأقل أسبوعياً.

## اختبارات محلية

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m http.server 8000
# افتح http://localhost:8000
```

لتجربة ماسح البيانات الفعلية بدون GitHub:

```bash
python scanner.py
```

ملاحظة: بعض المواقع تمنع الطلبات الآلية حتى مع استجابة المتصفح، وهذا يظهر كفشل مصدر ولا يعني عدم وجود اكتتابات. قد لا يكون Google News RSS شاملاً أو مستقراً، ولا يُستخدم وحده لاتخاذ قرار مالي.

## تطويرات مستقبلية مقترحة

- بيانات مالية موحدة ومراجعة لتقييم الإيرادات والسيولة والديون والقيمة السوقية قبل إضافة **أولوية بحث**؛ لا يتم اختراع درجة فرص نمو من أخبار الاكتتاب فقط.
- مواعيد محفزات للشركات المدرجة حديثاً مثل نتائج التجارب وموافقات FDA والعقود والإيرادات، مع مصادر رسمية.
- اختبار متابعة حقيقي على مدى 30 و90 يوماً قبل التفكير بأي استراتيجية تداول.
- خدمات رسمية أعمق للهند والخليج واليابان تتطلب واجهات بيانات موثوقة وحقوق استخدامها.

## ملاحظة أمان

لا يوجد اتصال بوسيط، ولا تخزن معلومات حساب تداول أو OpenAI keys داخل HTML أو ملفات المستودع العامة. لا يمكن معرفة الصعود المستقبلي مسبقاً. الاكتتاب الجديد قد يهبط بشدة وقد لا تستطيع شراءه بسعر الطرح. احترم لوائح وأسواق بلدك وضرائب الاستثمار.
